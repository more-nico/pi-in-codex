# 面板信息规划

面板用于查看由 Codex 主会话调度的 Pi 子任务，不是第二个聊天输入窗口。

## 宿主入口

- 菜单入口、面板页面标题统一显示为 **Pi in Codex**。
- MCP 服务通过 `serverInfo.icons` 提供内嵌 SVG 小图标，聊天入口可使用服务图标作为回退；
  页面 favicon 使用同一资产，构建后的 CLI 和面板均不需要额外请求图标文件。
- 当前桌面客户端会将 MCP 入口统一归入新标签页的“更多工具 → 插件和 MCP”。
  上方工具区由客户端内置工具占用，插件没有可声明的固定或排序选项。

## 信息层级

1. **顶栏**：组合 SVG Logo、右上角子对话切换入口。
2. **任务概览**：任务名称、一个生命周期状态标签；有模型信息时显示静态文字。
3. **主要内容**：已完成任务首先呈现最终 Markdown 总结；执行过程默认收起。
4. **次要信息**：过程中的工具调用、输入指令、用量只在展开过程后查看。
5. **页脚**：主会话调度说明和待接收结果数量，不占据正文的主要位置。

## 时间与导航

- 首次打开优先显示正在运行的任务，再考虑等待交互、启动中和排队任务；同类取最近的一次运行。
  全部结束时显示最近结束的结果。面板已打开后，新任务与追加消息只更新列表，不改变当前选择。
- 派活/发消息的工具返回 `panel.shouldOpen`：为 true 时主会话调用一次 `pi_panel`，一批任务只开一次；
  已打开或正在打开时不再调用。仅 `pi_panel` 关联 UI 资源，数据工具不重复渲染面板。
- `pi_poll` 携带当前面板实例 ID，用可取消的长轮询记录会话内的在线状态；轮询取消时释放实例，
  异常断线后的记录最多保留 45 秒。打开请求 10 秒未连接可重试。宿主仍需支持 MCP Apps 面板。
- 当前任务的耗时只出现一次：已完成时位于“用时 ×分×秒 ›”折叠行，其他状态位于进度行。
- 任务列表仅显示名称与活动状态，不重复耗时、token 或调用数。
- 任务列表是右上角悬浮层，默认折叠，不改变正文布局。未固定时选择任务、点击外部自动收起。
- 列表标题区可切换“固定悬浮”；固定后选择任务、点击正文仍保持展开。点击折叠控制或按 Escape
  可随时收起，重新展开时保留固定选择，右上角入口以图钉标识固定状态。
- 成功和失败任务都放入默认折叠的“已完成”分组；失败任务保留失败标记和错误信息。
  切回成功完成的任务时重新以总结视图打开。

## 过程与交互

- 点击用时行展开过程，箭头旋转、内容高度与透明度轻微过渡（约 200ms）。
- 总结始终留在过程下方，展开时不重复最终回复；隐藏的过程不能获得焦点。
- 遵守系统的减少动态效果设置；命令和工具输出在过程内进一步折叠。
- 同一次工具调用的参数与返回结果合并为一条折叠记录，按运行 ID 与调用 ID 配对；
  展开后分别查看参数和结果。调用尚未加载到当前消息页时，结果独立保留，加载历史后合并。
- 默认最近 50 条，主动查找历史才分页追加，保持阅读位置。
- 无输入框、发送、停止或确认表单；等待交互时只提示“等待主会话处理”。
- 指令、停止、交互回答与结果确认通过 Codex 主会话工具完成。

## 性能与长文本（源码更新，尚未发布）

- 自动刷新按聊天合并到最多约每秒 4 次；没有可见变化的思考/工具参数片段不触发重复刷新。
  主会话的等待、完成和交互通知独立处理，不使用面板的刷新限速。
- 面板使用 `transportVersion: 2`，传输消息窗口的 ID 和变化的消息；缓存缺失或守护重启后
  重新获取完整窗口。未带版本参数的旧面板仍使用原有格式。
- 消息和最终总结自动预览最多 8,000 个字符；主动阅读时每段最多 16,000 个字符。
  记录原文完整保留。历史分页仍为 50 条，工具折叠行显示预览字符数与总字符数。
- 折叠的工具详情和已完成任务的过程不挂载正文；收起后释放正文。静态消息复用渲染结果，
  app-only 轮询只返回结构化数据，避免额外复制一份 JSON 文本。
- 切换任务时释放上一个任务的已加载历史，后台任务仅保留最近窗口；已离开页面的历史请求
  返回后丢弃，避免重新填充不再阅读的内容。
