# 面板信息规划

面板用于查看由 Codex 主会话调度的 Pi 子任务，不是第二个聊天输入窗口。

## 信息层级

1. **顶栏**：产品名、当前聊天的连接状态、右上角子对话切换入口。
2. **任务概览**：任务名称、一个生命周期状态标签；有模型信息时显示静态文字。
3. **主要内容**：已完成任务首先呈现最终 Markdown 总结；执行过程默认收起。
4. **次要信息**：过程中的工具调用、输入指令、用量只在展开过程后查看。
5. **页脚**：主会话调度说明和待接收结果数量，不占据正文的主要位置。

## 时间与导航

- 当前任务的耗时只出现一次：已完成时位于“用时 ×分×秒 ›”折叠行，其他状态位于进度行。
- 任务列表仅显示名称与活动状态，不重复耗时、token 或调用数。
- 任务列表是右上角悬浮层，默认折叠，不改变正文布局。未固定时选择任务、点击外部自动收起。
- 列表标题区可切换“固定悬浮”；固定后选择任务、点击正文仍保持展开。点击折叠控制或按 Escape
  可随时收起，重新展开时保留固定选择，右上角入口以图钉标识固定状态。
- 完成分组默认折叠；切回已完成任务时重新以总结视图打开。

## 过程与交互

- 点击用时行展开过程，箭头旋转、内容高度与透明度轻微过渡（约 200ms）。
- 总结始终留在过程下方，展开时不重复最终回复；隐藏的过程不能获得焦点。
- 遵守系统的减少动态效果设置；命令和工具输出在过程内进一步折叠。
- 默认最近 50 条，主动查找历史才分页追加，保持阅读位置。
- 无输入框、发送、停止或确认表单；等待交互时只提示“等待主会话处理”。
- 指令、停止、交互回答与结果确认通过 Codex 主会话工具完成。
